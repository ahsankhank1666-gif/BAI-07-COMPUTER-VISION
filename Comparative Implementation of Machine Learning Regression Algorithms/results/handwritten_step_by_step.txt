House  x_i - x_bar  y_i - y_bar  product   squared x dev

H1     -0.15200     -2.76667     +0.42053  0.02310      
H2     -0.30600     -5.16667     +1.58100  0.09364      
H3     +0.45800     +7.93333     +3.63347  0.20976      

Step 3 - sums and coefficients:
  S_xy = sum((x_i-x_bar)(y_i-y_bar)) = 5.63500

2. DECISION TREE REGRESSION - CART variance reduction, 4 houses
==============================================================================

Feature = lstat; candidate split s = 4.505 (midpoint of 2.94 and 4.03)
Left  (lstat <= 4.505): ['H3', 'H4']  y = [34.7, 33.4]
Right (lstat >  4.505): ['H1', 'H2']  y = [24.0, 21.6]

Step 1 - parent impurity (MSE of a constant predictor):
  y_bar = (24.0 + 21.6 + 34.7 + 33.4) / 4 = 28.4250
  MSE_parent = ((24.0-28.4250)^2 + (21.6-28.4250)^2 + (34.7-28.4250)^2 + (33.4-28.4250)^2) / 4 = 32.5719

Step 2 - child impurities:
  left mean  = (34.7 + 33.4)/2 = 34.0500
  left MSE   = ((34.7-34.0500)^2 + (33.4-34.0500)^2)/2 = 0.4225
  right mean = (24.0 + 21.6)/2 = 22.8000
  right MSE  = ((24.0-22.8000)^2 + (21.6-22.8000)^2)/2 = 1.4400
  weighted child MSE = 2/4*0.4225 + 2/4*1.4400 = 0.9313

Step 3 - variance reduction (gain) of the split:
  gain = MSE_parent - weighted_child_MSE = 32.5719 - 0.9313 = 31.6406
  The algorithm picks the split with the LARGEST gain; leaf prediction = mean of y in leaf.

sklearn check: split threshold = 4.505, left leaf (node 1) = 34.0500, right leaf (node 2) = 22.8000  -> matches by hand

4. NEURAL NETWORK REGRESSION - one forward + backward pass, H1
==============================================================================

Tiny net: 2 inputs -> 1 ReLU neuron -> 1 linear output
Initial weights: w1 = [0.5, -0.2], b1 = -1.00, w2 = 0.80, b2 = 1.00
Input H1: x = [6.575, 4.98], target = 24.0

Step 1 - forward pass:
  z1   = w1.x + b1 = 0.5*6.575 + (-0.2)*4.98 + (-1.0) = 1.2915
  a1   = ReLU(z1) = max(0, 1.2915) = 1.2915
  y_hat = w2*a1 + b2 = 0.8*1.2915 + 1.0 = 2.0332
  L = 1/2*(y - y_hat)^2 = 0.5*(24.0 - 2.0332)^2 = 241.2702

Step 2 - backpropagation (chain rule):
  dL/dy_hat = y_hat - y = -21.9668
  dL/dw2 = dL/dy_hat * a1 = -28.3701
  dL/db2 = dL/dy_hat      = -21.9668
  dL/dw1 = dL/dy_hat * w2 * 1[z>0] * x = [-115.5454, -87.5157]
  dL/db1 = dL/dy_hat * w2 * 1[z>0] = -17.5734  (z>0 so neuron is active)

Step 3 - gradient descent update (eta = 0.001):
  w2_new = 0.8000 - 0.001*(-28.3701) = 0.828370
  b2_new = 1.0000 - 0.001*(-21.9668) = 1.021967
  w1_new = [0.615545, -0.112484], b1_new = -0.982427
  new prediction = 3.0967 (moved toward 24.0); new loss = 218.4737
  Repeat over all samples/epochs with Adam (full model: 64-32 ReLU layers, 314 iterations).
